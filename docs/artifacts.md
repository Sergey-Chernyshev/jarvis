# Файлы и комментарии в чате

Скрепка открывает выбор файла, сохраняя окно быстрого доступа до выбора или
отмены. Клик по вложению открывает предпросмотр до отправки. После отправки
вложение доступно из сообщения; файлы из ссылок агента, карточек изменений и
действий чтения/записи открываются в той же панели.

Панель показывает изображения с масштабом, PDF, Markdown, текст и исходный код,
статический HTML, аудио и видео в поддерживаемых WebKit форматах. На macOS Word
(DOC/DOCX) и RTF преобразуются в текст системным textutil; оформление Word не
воспроизводится. Неизвестный бинарный формат получает понятное состояние без
предпросмотра, но к нему можно оставить комментарий. Лимит файла — 25 МБ.

Файл удалённой сессии читается через её настроенное SSH/Teleport-подключение.
Локальный одноимённый путь не используется. Открываются обычные файлы проекта,
вложения Jarvis и файлы из фактов сессии; симлинки проверяются на машине файла.
Данные загружаются только при открытии файла пользователем. Для удалённого чтения
нужен python3 на узле. Устаревший результат загрузки не подменяет следующий файл.

Комментарии привязываются к файлу, выделенной цитате или точке на изображении.
Их можно редактировать и удалять. Они сохраняются на компьютере в
`~/.jarvis/artifact-notes/` (или `$JARVIS_DIR/artifact-notes/`). Идентификатор версии
— SHA-256 содержимого: заметки остаются с теми же байтами после загрузки вложения
на узел. Одинаковые копии файла разделяют заметки; новая версия имеет свой набор.
Черновики несохранённых заметок сохраняются при переключении файлов в окне.

«В чат» переносит комментарий и цитату/координаты в черновик сообщения исходной
сессии. Пользователь отправляет сообщение сам. Комментарии к PDF относятся ко
всему файлу; страницу можно указать в тексте заметки.

HTML отображается в изолированном iframe без выполнения скриптов и внешних
запросов. Для HTML и Markdown можно переключиться на исходник. Это просмотр
результата, а не редактор исходного файла; исходные файлы не меняются.

## Проверки

- `npm run test:ui` — общие UI-регрессии.
- `node scripts/qa/artifacts.cjs` — headless Chrome: выбор файла, предпросмотр,
  заметки/цитаты/точки, привязка к удалённой сессии, Word, настоящий PDF,
  устаревшие ответы, ошибка сохранения, узкий светлый интерфейс, Escape.
- `node scripts/qa/chat-input.cjs` — создание/отправка, вложения, сохранение
  проекта, мгновенное первое сообщение и подтверждение из истории.
- `cargo test --manifest-path src-tauri/Cargo.toml --bin jarvis artifacts::` —
  границы чтения и размер, реальные байты, сохранение заметок, конвертация DOCX.
- `cargo test --manifest-path src-tauri/Cargo.toml --bin jarvis attachments::` —
  бинарная загрузка, имена файлов и закрытие stdin до ожидания удалённого `cat`.

Системный диалог WKWebView и удалённая SSH-машина не подменяются браузерной
проверкой: браузер проверяет контракт focus guard и маршрутизацию, Rust —
исполняемый протокол файлов. Проверки выполняются без вывода окон перед пользователем.
