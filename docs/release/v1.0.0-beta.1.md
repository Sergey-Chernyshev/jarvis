# Jarvis 1.0 Beta 1

Первая бета большого обновления Jarvis: единое рабочее пространство для агентов,
проектов, терминалов, диктовки и встреч. Ниже — изменения относительно v0.3.3.

## Рабочее пространство

- Новое оконное оформление, светлая и тёмная темы, обновлённые иконки и настройки.
- Быстрая панель по ⌘J и отдельное рабочее окно с проектами и чатами.
- Поиск разделов и чатов по ⌘K, контекстные действия, навигация с клавиатуры,
  поиск конкретных параметров в настройках и поддержка русской раскладки.
- Каталог локальных и удалённых проектов: закрепление, фильтры, свои названия
  и аватары из файлов проекта или загруженной картинки.

## Агенты, чаты и терминалы

- Запуск и продолжение задач Claude Code и Codex из проекта, выбор модели,
  профиля, машины, разрешений и отдельного Git worktree.
- Встроенный терминал с поиском; работа с существующими терминальными сессиями.
- Многострочные сообщения и вложения, сохранение черновиков и первого сообщения
  во время подключения, ответы на вопросы агента с собственным вариантом.
- Просмотр файлов рядом с чатом: изображения, PDF, Markdown, код, статический
  HTML, аудио и видео поддерживаемых форматов; текстовый просмотр Word на macOS.
- Комментарии к файлам, цитатам и точкам на изображениях с переносом в черновик чата.
- Циклы, пайплайны и группы задач для автоматизации работы агентов.

## Удалённая работа

- Мастер подключения по SSH и Teleport, обнаружение профилей и моделей,
  локальные и удалённые чаты в одном интерфейсе.
- Linux-узлы для x86_64 и ARM64 встроены в macOS-приложение: установка узла
  больше не зависит от доступности отдельно опубликованного бинарника.
- История остановленных Codex-сессий на узле, устойчивее доставка событий,
  восстановление подключений и продолжение задач.
- Раздел «Машины и VM» с обнаружением управляемых Agent VM, запуском,
  остановкой и открытием конфигурации при поддержке установленного avm.

## Диктовка и встречи

- Обновлённая карточка диктовки, история записей, форматирование текста,
  настройки моделей и устройств ввода.
- Более надёжная вставка: Jarvis отслеживает исходное приложение и поле;
  при смене фокуса текст остаётся доступен для ручной вставки.
- Исправлены зависания при обнаружении микрофонов, завершении аудиодвижков
  и ожидании системных разрешений.
- Запись встреч с микрофона; на macOS 13+ — микрофон вместе со звуком приложений.
  Локальная расшифровка, архив и повторная обработка после ошибки.
- Запись длинных встреч идёт на диск; сохранённые встречи доступны для чтения через MCP.

## Аналитика и надёжность

- Аналитика наблюдаемой работы ИИ: сессии, инструменты, ошибки, токены,
  модели, результаты задач и расчётный эффект по введённым пользователем данным.
- Исправления статусов Claude/Codex, дубликатов событий, чтения UTF-8-истории,
  поздних ответов при переключении чатов и завершения дочерних процессов.
- Уведомления без перехвата фокуса, улучшения размещения на мониторах и Spaces.

## Установка и обновления

- **Бета-канал отдельный.** Для первого перехода с 0.3.x скачайте DMG этого релиза,
  закройте Jarvis и замените приложение в Applications. Следующие обновления
  бета-канала подписаны и устанавливаются встроенным апдейтером; применяются
  при следующем запуске. Обычный канал 0.3.x не переводится на бету автоматически.
- Готовое приложение: **macOS, Apple Silicon (M1 и новее)**. Для удалённых машин
  приложены Linux-узлы x86_64 и ARM64. Полного Linux desktop-пакета в этом релизе нет.
- Пользовательские настройки, история и записи хранятся вне приложения,
  в `~/.jarvis/` или `$JARVIS_DIR`; замена приложения их не удаляет.
- Сборка подписана ad-hoc, без нотариализации Apple. При первом запуске может
  понадобиться разрешить открытие в системных настройках безопасности macOS.

## Ограничения беты

- Это предварительный релиз; особенно полезна обратная связь по удалённым
  подключениям, диктовке, встречам и работе нескольких окон.
- У встреч пока нет разделения по говорящим и эхоподавления. Для записи
  онлайн-встреч рекомендуется использовать наушники; нужны системные разрешения.
- VM должна быть отдельно подключена по SSH для запуска чатов; обнаружение VM
  само по себе не создаёт транспорт и не разворачивает новую машину.
- Аналитика строится по доступным событиям и не является точным биллингом
  или доказательством авторства всех изменений.
